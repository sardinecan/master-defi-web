# Examen HTML-CSS M1 DEFI - 5 décembre 2025

Vous devez réaliser un CV (**réel** ou **fictif**) au format Web : une page HTML + une feuille de style CSS.

## Contraintes techniques

Le code HTML doit être conforme au standard HTML.

Le code CSS doit être conforme au standard CSS3.

Vous êtes libre du design (couleurs, polices, disposition, etc.).

Le CV peut contenir une photo (image trouvée en ligne).

## Livrables à déposer sur Cours en ligne

* Un fichier HTML nommé `prenom-nom-cv.html` ;
* un fichier CSS externe nommé `style.css` relié à votre page HTML.

## Contenu du CV

Votre CV doit inclure *a minima* les sections suivantes :

* **Présentation / contact** : nom, prénom, un petit texte d’accroche ou présentation, coordonnées (e-mail, éventuellement telephone ou adresse), et une photo ;
* **Formation** : diplômes, études, années — structuré clairement.
* **Expérience professionnelle** : emplois, stages, ou projets — avec dates et description.
* **Compétences** : techniques (langages, outils, etc.) et éventuellement compétences linguistiques ou autres.

Vous pouvez ajouter d’autres sections **si vous le souhaitez** (loisirs, centres d’intérêt, etc.).

## Consignes d’organisation

Utilisez des balises sémantiques appropriées : par exemple `<header>` pour l’en-tête, `<main>` pour le corps principal, `<section>` ou `<article>` pour les différentes rubriques, `<footer>`, etc.

Le contenu textuel doit être correctement structuré : titres de section, paragraphes / listes, clairement hiérarchisés.

Le code HTML et CSS doit être valide :

- Validator W3C : [https://validator.w3.org/](https://validator.w3.org/ )
- CSS Validator : [https://jigsaw.w3.org/css-validator/](https://jigsaw.w3.org/css-validator/)

Vous pouvez ajouter tout élément, class et identifiant que vous jugerez nécessaire pour mettre en place la mise en forme de votre CV.
