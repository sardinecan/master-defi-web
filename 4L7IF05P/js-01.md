# TP Javascript

## Préparation des fichiers

Dans un dossier, créez deux fichiers nommés :

* `index.html`
* `script.js`

Puis copiez le contenu suivant dans le fichier `index.html`

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>TP JavaScript</title>
  </head>
  <body>
    <h1>Hello World avec JavaScript !</h1>

    <p id="message"></p>

    <button id="btn">Cliquez sur moi !</button>

    <script src="script.js"></script>
  </body>
</html>
```

`script.js` est chargé à la fin du fichier grâce à `<script src="script.js"></script>`

## Dans le navigateur

Ouvrez la page `index.html` dans votre navigateur, puis consultez la console :

`Clic droit → "Inspecter" → onglet "Console"`

La console permet de voir ce que JavaScript affiche ou s’il y a des erreurs.


## Hello World!

Ouvrez `script.js` dans votre éditeur de texte, puis ajoutez :

`console.log("Hello World!");`

Actualisez ensuite votre page web pour voir s'afficher le message `Hello World!` dabs la console.

La commande `console.log()` sert à afficher un message pour vérifier que votre code fonctionne.

## Les variables

Modifiez votre fichier `script.js` en ajoutant :

```js
let prenom = "Alice";
let age = 30;

console.log(prenom);
console.log(age);
```

En rechargeant votre page, la console doit afficher :

```text
Alice
30
```

Une *variable* est un espace de mémoire **nommé** qui permet de stocker une donnée.

## Interagir avec HTML

Dans `script.js`, ajoutez :

`document.getElementById("message").textContent = "Hello World (from Javascript!)";`

Après rechargement, le texte doit apparaître directement dans votre page.

L'*objet* `document` représente votre page web. La *méthode* `getElementById()` permet d'accéder à un élément par son identifiant qui lui est indiqué en *argument* (ici `"message"`). La *propriété* `textContent` permet de définir le contenu de l’élément.

## Les évènements

Dans `script.js`, ajoutez ce code :

```js
document.getElementById("btn").addEventListener("click", function() {
  alert("Vous avez cliqué !");
});
```

En cliquant sur le bouton, une boite de dialogue s'affiche.

La méthode `addEventListener()` permet de définir une fonction qui sera appelée à chaque fois que l'évènement spécifié est envoyé à la cible. Le premier *argument* correspond au type d'évènement attendu, ici lorsqu'on clique sur le bouton, et le second correspond à la fonction qui est appelée.

## Remplacer du contenu

Remplacez l’alerte par :

`document.getElementById("message").textContent = "Vous avez cliqué !";`

Lorsque vous cliquez sur le bouton, le texte de votre paragraphe est modifié.

## Hello World interactif

Dans index.html, ajouter ceci juste avant la balise `<script>` :

```xml
<br/>
<label>Votre nom : </label>
<input id="nom" type="text">
<button id="saluer">Say Hello</button>
<p id="resultat"></p>
```

La balise `<input>` est un champ texte. Le bouton déclenchera le Javascript, et la réponse s'affichera dans `<p id="resultat"></p>`.

Dans `script.js`, ajoutez :

```js
document.getElementById("saluer").addEventListener("click", function() {
  let nom = document.getElementById("nom").value;

  console.log("Nom tapé :", nom);
});
```
La *propriété* `value` permet de récupérer le texte tapé dans l'`input`.

Remplacez ensuite le message console par :

```js
if (nom === "") {
    document.getElementById("resultat").textContent = "Veuillez entrer un nom.";
} else {
    document.getElementById("resultat").textContent = "Hello " + nom + " !";
}
```

`if()` / `else` sont des tests, si la variable `nom` est vide (`nom === ""`) alors il faut afficher "Veuillez entrer un nom", sinon on réalise une concaténation grâce à l'opérateur `+` et on affiche le résultat de cette concaténation.
