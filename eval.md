Évaluation HTML/CSS terminale

Réalisez un petit site web (1-2 pages, 3 maximum) sur un sujet de votre choix (p. ex. passion/hobby, courant artistique, groupe de musique/personnalité favorit(e), film, œuvre d’art, etc.).

Partie HTML

Vous veillerez au respect de la syntaxe HTML et à structurer correctement vos données, en utilisant notamment le balisage sémantique. Votre page ou votre site doit également comporter une navigation.

Partie CSS

L’évaluation portera également sur le respect de la syntaxe CSS ainsi que sur l’application et la compréhension des concepts vus en cours (héritage, cascade, box model, positionnement, etc.).

Votre implication sera prise en compte. Cet exercice doit être l'occasion d'approfondir et de mettre en pratique certaines propriétés CSS, dans le cadre d'un usage avancé. Vous pourrez vous appuyer sur le travail et les articles de designers web tels que Jen Simmons et Rachel Andrew sur les grilles CSS, Matej Latin sur la typographie ou encore Ahmad Shadeed, Chris Coyier, etc. - la liste n'est pas exhaustive -. Le site <https://la-cascade.io> propose des traductions de certains articles en français.

Attention, il ne s'agit pas de copier leurs exemples tels quels, mais bien de les adapter à votre projet. Vous rédigerez une courte bibliographie des articles et lectures utilisés pour la réalisation de votre site web.

Vous penserez enfin à commenter votre code, afin de justifier vos choix, indiquer vos réussites, mais également vos échecs !

Les critères purement esthétiques n'entrent pas en compte pour la notation.

Organisation des fichiers

Les fichiers composants votre site web doivent être organisés : 

    le(s) fichier(s) HTML doi(ven)t être à la racine et la première page est toujours nommée index.html ;

    le(s) fichier(s) CSS doi(ven)t être dans un sous-dossier css ;

    les fichiers média (images/vidéos, etc.) doivent être dans un sous-dossier assets, puis répartis par catégorie ;

    l’ensemble doit être fonctionnel sur n’importe quelle machine ;
    un README doit être présent pour présenter votre projet et votre bibliographie ;
    Le tout sera compressé (fichier .zip, .rar, etc.) pour être déposé sur cours en ligne. La limite de taille est fixée à 20mo (le maximum). Attention donc si vous avez de nombreuses photos et/ou vidéos.


projetMonNom/             # Dossier de travail
├── index.html            # Page principale, toujours index.html
├── about.html            # Deuxième page (si besoin, par exemple, une page "À propos")
├── assets/               # Dossier pour les fichiers multimédia
│   ├── images/           # Images du projet (si besoin)
│   │   └── photo.jpg
│   ├── videos/           # Vidéos du projet (si besoin)
│   │   └── video.mp4
│   └── fonts/            # Polices de caractères personnalisées (si besoin)
│       └── font.woff
├── css/                  # Dossier pour les feuilles de style
│   ├── main.css          # Feuille de style principale
│   └── typo.css          # CSS spécifique pour la typographie par exemple
└── README.md             # Documentation et bibliographie du projet, fichier.txt ou.md
